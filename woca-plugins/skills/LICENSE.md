## Adaptation policy

Each SKILL.md carries an attribution header describing the woca adaptations:
`superpowers:<name>` cross-references de-namespaced to local skill names,
Claude Code tool references mapped to woca equivalents (Task tool,
EnterWorktree), upstream-only sections dropped (visual companion,
runtime-specific paths), and companion reference files inlined so each
skill is self-contained. Upstream license below applies to the original
text; re-vendoring on upgrade: fetch at the pinned-or-newer commit, re-run
the adaptation, and update the pin in this file and the SKILL.md headers.
