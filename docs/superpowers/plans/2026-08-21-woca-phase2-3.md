# woca Phase 2 & Phase 3 Implementation Plan

> SDD: execute task-by-task with tests; every task keeps `woca serve`
> (modular-monolith) fully working — the dual-form regression baseline.

**Spec:** `woca-微服务化改造设计.md` §13 roadmap (Phase 2: state externalization,
queuing, observability; Phase 3: worker/sandbox/skill-svc v1).

**Frontend convention (user directive):** all frontend work standardizes on
**bun + Vue 3 + vue-i18n** (zh-CN + en, namespaced locale modules like
`web/src/i18n`); the existing `web/` npm tooling migrates to bun
(drop-in: `bun install` / `bun run build`), and the skill-svc console SPA
(Phase 3) is built with bun from day one.

## Phase 2 — state externalization, queueing, observability

- [x] **T0 memory.Engine remote** (done 2026-08-21, cb64de8/e96db9c:
  ladyM v0.4.0 client, workspace mapping `woca:{t}:{u}:{ws}`, Recall
  float-up, breaker degradation, live e2e against docker ladyM).
- [x] **T1 runs/run_events tables + RunLedger** (faa8f9e) — wocadb migration
  (`runs`: id/session/tenant/owner/lease/status/config snapshot;
  `run_events`: run_id/seq/kind/payload), tenant_id + RLS following the
  Phase-1 GUC pattern; `internal/runstate` ledger: Append/Replay/
  LeaseClaim/Heartbeat/ReapExpired (reconciler). Tests: sqlite semantics +
  lease expiry adoption + replay ordering.
- [x] **T2 admission → store constraint** (fbee71a) — the server registers
  every executing run born-running under its instance lease (Ledger.Start),
  thread_id minted server-side and pinned into the runner (WithThreadID);
  the one_active_run_per_session constraint rejects cross-instance double
  execution, a 30s heartbeat extends the lease, a lost lease cancels the
  local run, terminal events map onto the row. Unlocks T7 (thread
  ownership) and T3 (event mirroring).
- [x] **T3 PG bus (cross-instance SSE)** (b338eed: run events mirrored into run_events under the SSE id; ledger-polled SSE fallback with Last-Event-ID resume; ledger calls run in tenant transactions) — `internal/platform/eventbus/pg.go`

  hub→PG bus only when postgres backend; local bus remains default.
- [x] **T4 telemetry 切面** (14d47ba: internal/telemetry OTel GenAI attrs, local=structured log; wired into tools/model/skills; run-scoped ctx tags) — `internal/telemetry`: spans for skill
  load/activate, tool pre/post, LLM call; attributes aligned to OTel GenAI
  semantics; local sink = structured log + run_events rows (tenant/run/
  session + asset id+version labels). Wire into tools registry + model
  invoke + skill loader.
- [x] **T5 transcript → BlobStore** (4745d2a: single JSONL codec, SaveBlob/LoadBlob, sessionStore bodies through the seam, legacy layout loads unchanged) — session transcripts written through
  `platform/blobstore` (Local impl already exists); S3 impl deferred to
  enterprise deploy (interface stays).
- [x] **T6 memory export/import tool** (4dd15f6) — console command migrating personal
  sqlite ladyM memories → remote/enterprise (via Engine interface).
- [x] **T7 checkpoint tenancy** (946eba9: lgcp schema pre-created + SECURITY DEFINER thread_owner RLS; upstream saver search_path; live PG verification incl. saver e2e) — ownership mapping (run rows carry thread ids) +
  RLS subquery policy per the 2026-08-20 design decision (upstream-faithful:
  no tenant column in lgcp_checkpoints).
- [x] **T8 acceptance** (c413ddd: dead-instance lease adoption via the periodic reconciler; two-tenant memory key isolation; cross-instance visibility/SSE resume from T3; PG ledger paths live-tested; full-suite green) — two in-process Server instances sharing one DB:
